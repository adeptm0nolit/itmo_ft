## Задание 4

Программа *task_4.py* считывает данные из файла *CdSe_CdZnS Core_Shell.txt* и считает среднее значение и среднеквадратичное
отклонение и выводит ответ таким образом:

1. x, y две случайные величины: Ответ **mean_dev(x)**, **mean_dev(y)**, **std_dev(x)**, **std_dev(y)**
2. Это ненормированное распределение величины X: Ответ **mean_dev(x)**, **std_dev(x)**
3. x - это например длинны волн (похоже 400 нм - 800 нм = видимый свет), y - какая-то энергия или плотность потока 
(правда непонятно почему есть отрицательные числа в y): Ответ **mean_dev(y)**, **std_dev(y)**
